# 💫 About Me

I'm a cybersecurity and AI enthusiast passionate about building intelligent systems, security platforms, and autonomous solutions. I explore the intersection of cybersecurity, AI engineering, and software development — turning complex ideas into practical tools.

My work includes autonomous cyber defense, AI-assisted security investigation, AI guardrails, AI-agent security, and intelligent developer environments.

I enjoy turning ambitious ideas into working software. I believe the best way to learn technology is to experiment, test assumptions, break things in controlled environments, and build something better.
